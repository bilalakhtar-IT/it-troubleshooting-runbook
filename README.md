# IT Troubleshooting Runbook

Series of common troubleshooting guides for IT support and helpdesk issues.

## Issues This Project Includes

Each of these folders groups a category of common Helpdesk issues. Every guide includes symptoms, possible causes, resolution steps, and when escalation is needed. When needed, link to guides have been provided for further reference.

| Category | Covers |
|---|---|
| Account & Access | Lockouts, password resets, MFA, shared drive access |
| Hardware | Boot failures, printer issues |
| Network | Internet connectivity, DNS, DHCP, VPN |
| Performance | Slow systems, high CPU/memory, low disk space |
| Software | Outlook, Microsoft Teams |
| Windows | System crashes (BSOD), update failures |

17 guides total, and growing.

## Each Problem Guide Includes

- Common symptoms
- Possible causes
- Troubleshooting steps
- When escalation is needed

## Project Goal

The main purpose of this project is to understand common/practical IT support and helpdesk skills and to document easy to follow troubleshooting steps for technical problems.
