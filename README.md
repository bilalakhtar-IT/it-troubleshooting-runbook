# IT Troubleshooting Runbook

Series of common troubleshooting guides for IT support and helpdesk issues.

## What Problems This Includes

This project includes guides for:

- Account lockouts
- Computer not booting
- No internet connection
- Slow/unresponsive computer
- Outlook not opening/responding or crashing

## Each problem guide includes:

- Common symptoms
- Possible causes
- Troubleshooting steps
- When escalation is needed

## Skills

This project has allowed me to understand skills of:

- IT troubleshooting
- Helpdesk support
- Windows troubleshooting
- Active Directory
- Basic networking
- Technical ticket Documentation
- Problem escalation

## Project Goal

The main purpose of this project is to understand basic/practical IT support and helpdesk skills and to document easy to follow troubleshooting steps for technical problems.

## Moving Forward

This project will be updated regularly with more troubleshooting guides that will cover common IT and helpdesk problems that are faced within the industry.
