# MFA Login Issue

## Symptoms

- User unable to complete MFA during sign in
- MFA code not working
- MFA notification is not being sent
- Unable to access acount after signing in

## Possible Causes

- MFA possibly expired
- Using old or incorrect code
- MFA app is not functioning as intended
- MFA method needs to be reset

## Resolution Steps

1. Confirm user identity before making any changes on their account
2. Confirm correct MFA code is being inputted
3. Make user request new code and retry
4. Check for proper network connection
5. Retsart or update MFA app
6. Have user try out new MFA method

**Guide:** [Set up security info to use two-step verification](https://support.microsoft.com/en-us/accounts-billing/work-school/set-up-security-info-from-a-sign-in-page)

## Escalation

Escalate issue if:

- User still unable to complete MFA sign in
- MFS method needs to be reset
- Lost access to their device with MFA
- Security concern within account
- Need admin access
