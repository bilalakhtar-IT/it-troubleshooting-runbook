# MFA Login Issue

## Symptoms

- User unable to complete MFA during sign in.
- MFA code not working.
- MFA notification is not being sent.
- Unable to access account after signing in.

## Possible Causes

- MFA code possibly expired.
- Using old or incorrect code.
- MFA app is not functioning as intended.
- MFA method may need to be reset.

## Resolution Steps

1. Confirm user identity before making any changes to their account.
2. Confirm the correct MFA code is being entered.
3. Have the user request a new code and retry.
4. Check for a proper network connection.
5. Restart or update the MFA app.
6. Have the user try another available MFA method.

**Guide:** [Set up security info to use two-step verification](https://support.microsoft.com/en-us/accounts-billing/work-school/set-up-security-info-from-a-sign-in-page)

## Escalation

Escalate issue if:

- User is still unable to complete MFA sign in.
- MFA method needs to be reset.
- User lost access to their device with MFA.
- There is a security concern with the account.
- Admin access is needed.
