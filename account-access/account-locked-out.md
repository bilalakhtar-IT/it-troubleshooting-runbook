# User Account Locked Out

## Symptoms

- User unable to log into their computer or apps.
- Receiving "Account Locked" message
- Password is being denied
- Company email/resources unable to be used

## Possible Causes

- Too many incorrect password attempts
- Logged into an old device with same password
- Failed to login with a connected device
- Account security locked user out

## Resolution Steps

1. Verify user is logging into their work appointed device with their login credentials
2. Check if account is locked
3. In Active Directory Users unlock users account
    - Open Active Directory Users and Computers
    - Find the user’s account
    - Right-click the account > Properties
    - Select the Account tab
    - Check Unlock account
    - Click Apply > OK
4. Make user log in to make sure and confirm their access

## Escalation

- Escalate issue if account is constantly locking user out after unlocking account
- Issue needs to be escalated if there are unauthorized login attempts
- Document all findings of situation and escalate
