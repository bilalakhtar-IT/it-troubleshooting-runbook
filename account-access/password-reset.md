## User Account Password Reset

## Symptoms

- User cannot remember their password
- Unable to sign in to their account
- Receiving incorrect password message
- Multiple failed attempts caused lock out

## Possible Causes

- Forgotten password
- User entered incorrect password several times
- Password may have expired
- Account may be locked due to security purposes

## Resolution Steps

1. Confirm user ID before resetting their password
2. Check if account is locked out or if password expired
3. Reset password using management tool
    - Open Active Directory
    - Locate user account
    - Right click user name
    - Select reset password
    - Type and confirm new password
    - Check "User must change password at next logon" if they want to create personal password
4. Provide user with steps on how to create their own password following company security guidelines

## Escalation

Escalate the issue if:

- Password reset does not resolve problem
- Account unable to be unlocked
- User unable to sign in after password reset
- Security issue within account
