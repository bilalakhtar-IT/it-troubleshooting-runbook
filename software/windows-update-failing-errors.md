## Windows Update Failing/Errors

## Symptoms

- Windows Update failing to install
- Update freezes during download phase or installation
- User receiving error code
- User asked to try again after each attempt

## Possible Causes

- Internet connection issue
- Low storage space
- Windows Update service is not running properly
- Update files are corrupted
- Running background program causing error

## Resolution Steps

1. Confirm computer has stable internet connection
2. Check how much storage is available on computer
3. Restart and try updating Windows again
4. Run Windows Update troubleshooter
5. Check for any error code being displayed
6. Copy error code and find specific solution for said code

**Guide:** [Troubleshoot problems updating Windows](https://support.microsoft.com/en-us/windows/deployment/updates-lifecycle/troubleshoot-problems-updating-windows)

## Escalation

Escalate issue if:

- Windows update is still failing to update
- Same error code is appearing
- Several computers are facing same issue
- If error code is hardware failure
