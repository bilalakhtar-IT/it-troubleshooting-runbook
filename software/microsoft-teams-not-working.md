## Microsoft Teams Not Working

## Symptoms

- Microsoft Teams won't open
- Teams not responding or is constantly crashes
- User unable to connect to Teams
- Messages are not loading
- Features are not working as intended

## Possible Causes

- Teams needs to be restarted
- Internet connection issue
- Teams cache may need to be cleared
- Teams needs an update
- Microsoft Teams service is down

## Resolution Steps

1. Confirm user is connected to internet
2. Restart Teams
3. Sign out of Teams and sign back in
4. Check for any updates
5. Clear cache
6. Check if Teams is working through web browser version 
7. Check to see if Microsoft or Teams is down

**Guide:** [Troubleshoot in Microsoft Teams](https://support.microsoft.com/en-us/teams/platform/troubleshoot-in-microsoft-teams)

## Escalation

Escalate issue if:

- Teams continues to crash or won't open
- Multiple users are experiencing same issue
- Possible Microsoft 365 service outage
- Admin needs to give user access again to Microsoft Teams
