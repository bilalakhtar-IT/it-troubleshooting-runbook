# Microsoft Teams Not Working

## Symptoms

- Microsoft Teams won't open.
- Teams is not responding or constantly crashes.
- User is unable to connect to Teams.
- Messages are not loading.
- Features are not working as intended.

## Possible Causes

- Teams needs to be restarted.
- Internet connection issue.
- Teams cache may need to be cleared.
- Teams may need an update.
- Microsoft Teams service may be down.

## Resolution Steps

1. Confirm the user is connected to the internet.
2. Restart Teams.
3. Sign out of Teams and sign back in.
4. Check for any available Teams updates.
5. Clear the Teams cache if the issue continues.
6. Check if Teams is working through the web browser version.
7. Check if there is a Microsoft Teams service outage.
8. Have the user test Teams again to confirm the issue is resolved.

**Guide:** [Troubleshoot in Microsoft Teams](https://support.microsoft.com/en-us/teams/platform/troubleshoot-in-microsoft-teams)

## Escalation

Escalate issue if:

- Teams continues to crash or won't open.
- Multiple users are experiencing the same issue.
- There is a possible Microsoft 365 service outage.
- Admin access is needed to restore the user's access to Microsoft Teams.
