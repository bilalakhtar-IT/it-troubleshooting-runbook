## Printer Not Printing

## Symptoms

- Printer is not printing users document
- Printer displaying offline
- Print job is stuck in queue
- Printer unable to print for all other users

## Possible Causes

- Printer is offline or disconnected
- Ran out of paper or ink/toner
- User selected incorrect printer
- Need to update printer driver
- Experiencing network connection problems

## Resolution Steps

1. Confirm printer is powered on and connected
2. Look for any error messages on printer
3. Check paper and ink/toner status
4. See if user has selected correct printer on their computer
5. Check if printer is showing online
6. Clear print queue and print a test page
7. Restart printer and retry to confirm

**Guide:** [Fix printer connection and printing problems in Windows](https://support.microsoft.com/en-us/windows/hardware/printer/fix-printer-connection-and-printing-problems-in-windows)

## Escalation

Escalate the issue if:

- Printer still won't work after troubleshooting
- Printer has hardware error
- Other users are unable to print
- Unable to connect to network
- If printer needs admin access
- Document all steps before escalating ticket
