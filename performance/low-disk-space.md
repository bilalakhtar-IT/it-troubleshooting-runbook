# Low Disk Space

## Symptoms

- User receiving a low storage warning.
- Device is running slower than usual.
- Unable to save or download files.
- Windows or other updates are failing.

## Possible Causes

- Too many personal or work files.
- Temporary files are taking up too much space.
- Recycle Bin is full of deleted files.
- Large apps or files are using available storage.

## Resolution Steps

1. Check how much available storage there is on the computer.
2. Identify what is using the most storage.
3. Delete unnecessary temporary files.
4. Empty unnecessary files from the Recycle Bin.
5. Remove or move any unneeded files.
6. Uninstall apps that are no longer in use.
7. Check the available storage again to confirm space has been freed.

**Guide:** [Free up drive space in Windows](https://support.microsoft.com/en-us/windows/experience/storage-filemanagement/free-up-drive-space-in-windows)

## Escalation

Escalate issue if:

- Computer continues to run out of storage.
- Important files need to be recovered or moved.
- There may be an issue with the storage drive.
- Admin access is needed.
