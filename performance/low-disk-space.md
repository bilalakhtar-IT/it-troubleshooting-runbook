# Low Disk Space

## Symptoms

- User receiving low storage warning
- Device is running slower than usual
- Unable to save or download files
- Windows and other updates failing

## Possible Causes

- Too many personal or work files
- Temp files taking up too much space
- Recycling bin full of deleted files
- Large apps. or files are using available storage

## Resolution Steps

1. Check how much available storage there is on computer
2. Identify what is using the most storage
3. Delete all unnecessary temp files 
4. Empty files in the Recycle Bin
5. Remove or move any unneeded files
6. Uninstall apps. that are no longer in use

**Guide:** [Free up drive space in Windows](https://support.microsoft.com/en-us/windows/experience/storage-filemanagement/free-up-drive-space-in-windows)

## Escalation

Escalate issue if:

- Computer continues to run out of storage
- Important files need to be recovered or moved
- Hardware may be failing
