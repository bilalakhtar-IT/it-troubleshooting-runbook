# Slow Computer

## Symptoms

- User reported that their computer was running really slow 
- Observed that pages are loading very slowly and apps are either loading slowly or crashing
- Noticed that keyboard and mouse clicks have input delay

## Possible Causes

- Several days without retarting/shutting off computer
- Multiple tabs/apps. open
- Pending updates waiting to be completed

## Resolution Steps

1. I would ask if the computer has been restarted
2. I would close all tabs and apps that were open to see if there is any improvement on speed
3. I would check to see if there are any new pending updates that are needed to be done 
4. I would restart the PC after/if any updates were done to see if that will fix the issue

## Escalation

- When all troubleshooting processes are done and no fix. It will need to be escalated to senior who will check the hardware of the computer
