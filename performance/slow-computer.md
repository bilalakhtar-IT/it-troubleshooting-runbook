# Slow Computer

## Symptoms

- User reported that their computer is running really slow.
- Pages are loading slowly and apps are either loading slowly or crashing.
- Keyboard and mouse clicks have an input delay.

## Possible Causes

- Computer has not been restarted or shut down for several days.
- Multiple tabs or apps are open.
- Pending updates are waiting to be completed.
- Background programs may be using system resources.

## Resolution Steps

1. Ask if the computer has recently been restarted.
2. Close unnecessary tabs and apps to see if there is any improvement in speed.
3. Check Task Manager for any apps or processes using a high amount of CPU or memory.
4. Check for any pending Windows updates and install them if needed.
5. Restart the computer after any updates and check if performance has improved.

## Escalation

- Computer is still running slowly after troubleshooting.
- Computer continues to freeze or crash.
- A possible hardware issue is found.
- Advanced troubleshooting or admin access is needed.
